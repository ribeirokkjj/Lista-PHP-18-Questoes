# Atividades PHP 01 a 06

Estou usando um compilador online para executar os códigos: https://onecompiler.com/php

Este projeto reúne exercícios em PHP organizados por numeração. Cada arquivo `ex_0x.php` contém uma solução simples e isolada, focada em uma função específica.

## Atividade 1
Calcula a fórmula `((x² + y²) / (x + y))`.
Antes de fazer a conta, o código verifica se a soma de `x + y` é zero para evitar divisão por zero.

## Atividade 2
Inverte um texto com `strrev()`.
Além do texto invertido, o script também exibe o texto original e a quantidade de caracteres.

## Atividade 3
Mascara um CPF, mostrando apenas os 4 últimos dígitos.
Os demais caracteres são substituídos por `*`.

## Atividade 4
Gera uma senha aleatória com tamanho definido em uma variável.
A senha usa letras maiúsculas, letras minúsculas, números e símbolos.

## Atividade 5
Analisa um texto e retorna algumas informações sobre ele.
O script conta caracteres, vogais e consoantes e também percorre o texto caractere por caractere.

## Atividade 6
Converte uma temperatura em Celsius para Fahrenheit e Kelvin.
O resultado é exibido em uma frase com as três representações.

## Atividade 7
Aplica um desconto com base no valor final da compra.
O resultado é exibido em uma frase com o valor inicial e com desconto.
